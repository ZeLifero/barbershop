# Gentlemen's Club — Frontend

Первая версия frontend для учебного портфолио: сайт барбершопа + демонстрационная панель администратора. Проект уже запускается через Node.js + Express, пока Express только раздаёт статические файлы.

## Запуск через Node.js

1. Установите Node.js (рекомендуется LTS): https://nodejs.org/
2. Распакуйте архив и откройте папку проекта в VS Code.
3. Откройте терминал VS Code: **Terminal → New Terminal**.
4. Убедитесь, что терминал находится в папке проекта.
5. Выполните:

```bash
npm install
npm start
```

6. Откройте в браузере `http://localhost:3000`.
7. Панель администратора: `http://localhost:3000/admin.html`.

Остановить сервер можно сочетанием `Ctrl + C` в терминале.

## Что реализовано

- Адаптивная главная страница.
- Блоки «О нас», услуги, мастера, галерея, контакты.
- Форма записи с базовой проверкой полей.
- Демо-сохранение заявок в `localStorage`.
- Демо-панель администратора: просмотр и удаление заявок.
- Мобильное меню.
- Express-сервер для раздачи frontend.

## Важно: текущие ограничения

Это только frontend-прототип. Заявки сохраняются в браузере конкретного устройства и не попадают на сервер. Демо-пароль панели `club2026` хранится в JavaScript и не обеспечивает безопасность. Не используйте эту авторизацию в реальном проекте и не вводите настоящие персональные данные.

На следующих этапах заменим `localStorage` на API Node.js/Express, подключим PostgreSQL через Prisma, реализуем серверную авторизацию администратора и интеграцию Telegram-бота.
